Masonic Fonts

This collection includes Masonic cipher fonts, decorative symbols, and historic Greek and Hebrew fonts. Each download is provided as a ZIP file containing the original font files and any available documentation.

After downloading a font, extract the ZIP file before installing it. Please read any included documentation for usage and distribution information.

Masonic Cipher Font

A Masonic cipher font created for the original MasonicCD software in 2003. Uppercase letters produce heavier double-line cipher characters, while lowercase letters produce simpler single-line characters.

Includes: TrueType font, character chart, and instructions

Created by: JTM eServices, 2003

Distributed by: MasonicWorld.com

Download ZIP

MasonicWorld Graphics Font

MasonicWorld Graphics is a decorative TrueType font containing 26 Masonic illustrations. Each uppercase letter from A through Z produces a different graphic. The font can be used for certificates, newsletters, lodge publications, presentations, educational materials, and other decorative projects. The graphics contain fine detail and generally look best at larger sizes.

Includes: TrueType font, character chart, and instructions

Created by: MasonicWorld.com

Distributed by: MasonicWorld.com

Download ZIP

Kadosh Samaritan

A Samaritan alphabet font designed for the study and display of Samaritan writing. The original manual includes installation instructions, keyboard mappings, and terms of use.

Includes: TrueType font and original PDF and TXT manuals

Created by: Shawn Eyer

Version: 1.1

Permission: Redistributed with the author's permission and original documentation

Download ZIP

Royal Arch Ciphers

A collection of three historic cipher fonts: Royal Arch, Illuminati, and Nug-Soth. The Royal Arch font provides two common arrangements mapped to uppercase and lowercase letters.

Includes: Three TrueType fonts and original documentation

Created by: Nu Isis Working Group

License: Freeware; embedded font information must remain intact

Download ZIP

Masonic Dings

A collection of 22 detailed Masonic and fraternal illustrations, including working tools, the square and compasses, the all-seeing eye, ornamental frames, and other traditional imagery.

Includes: TrueType font and original documentation

Created by: Listemageren, 1998

License: Postcardware; freely distributable with the original documentation

Download ZIP

Scholars Press Greek and Hebrew Fonts

Two public-domain biblical-language fonts from Scholars Press. SPIonic provides Greek characters, while SPTiberian provides Hebrew and Aramaic characters.

Includes: Two TrueType fonts

Created by: Jimmy Adair for Scholars Press

Note: These are legacy keyboard-mapped fonts created before modern Unicode language support became standard
