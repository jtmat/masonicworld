MasonicWorld Lodge Event Seating Planner
==========================================

FIRST TEST BUILD

How to run
----------
1. Extract this ZIP file.
2. Double-click index.html.
3. The planner should open in your normal web browser.
4. No installation or web server is required.

Current features
----------------
- Event name and date
- Multiple sessions/plans within one event
- Round, square, and rectangular tables
- Move, resize, and rotate tables
- Add/remove seats
- Add people with meal choices and short notes
- Drag people from the list onto seats
- Click a person, then click a seat as an alternative to drag-and-drop
- Room objects: Head Table, Podium/Lectern, Stage, Entrance, Dance Floor
- Move, resize, and rotate room objects
- Save event to a local .mwseat file
- Open a saved .mwseat file later
- Print / Save as PDF using the browser print dialog
- Print a simple alphabetized meal sheet (Name | Meal)
- Export meal information to CSV for Excel / Google Sheets
  (Name, Meal, Note, Table, Seat for the active session)

Important
---------
The .mwseat file is the event file. Keep it in OneDrive, Google Drive Desktop,
Dropbox, or another folder that is backed up/synchronized if desired.

This build intentionally does NOT include:
- Accounts or logins
- Cloud database
- RSVP management
- Invitations
- Payments
- Eventbrite-style event management
- A special U-shaped table object

U-shapes, T-shapes, long rows, and similar arrangements can be assembled from
rectangle and square tables.

Primary use is desktop/laptop. Mobile display is secondary.
