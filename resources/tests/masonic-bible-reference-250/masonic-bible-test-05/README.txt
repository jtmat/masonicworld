MASONICWORLD - THE BIBLE IN MASONRY TEST 05
===========================================

CONTENTS
--------

This package contains questions 201-250 in the Bible in Masonry series.

The questions continue with the unused supporting references for The Master
Builder and proceed through the remainder of printed page 13, ending with The
Eternal Rest. Every question is based on an association expressly printed in
the source. Quoted passages are tested directly; citations printed as "See
also" references are matched only to their documented Masonic subjects.

There are no general Bible-trivia questions and no difficulty classifications.
Each attempt selects 10 completely random questions from the 50-question bank.
Questions and answer choices are shuffled each time, and missed questions are
reviewed at the end.


FILES
-----

index.html     Test page
styles.css     Test appearance
questions.js   The 50-question bank and private source notes
test.js        Reusable test program and configuration


SOURCE
------

The question bank was prepared directly from bible-quotes.pdf, titled The Bible
in Masonry. The internal source notes distinguish quoted passages from "See
also" citations and identify the Masonic heading supporting every answer.
Obvious citation misprints were corrected without expanding beyond the source.


USE
---

Keep all five files in the same folder. Open index.html in a browser to run the
test locally, or upload the folder to the website.
