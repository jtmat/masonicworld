MASONICWORLD - THE BIBLE IN MASONRY TEST 04
===========================================

CONTENTS
--------

This package contains questions 151-200 in the Bible in Masonry series.

The questions continue with The Fords of the Jordan on printed page 11 and
proceed in source order through The Master Builder on printed page 13. Every
question tests a relationship expressly presented in the source through a
varied mix of quotation identification, passage content, and matching a Bible
reference with its Masonic subject.

There are no general Bible-trivia questions and no difficulty classifications.
Each attempt selects 10 completely random questions from the 50-question bank.
Questions and answer choices are shuffled each time, and missed questions are
reviewed at the end.


FILES
-----

index.html     Test page
styles.css     Test appearance
questions.js   The 50-question bank and private source notes
test.js        Reusable test program and configuration


SOURCE
------

The question bank was prepared directly from bible-quotes.pdf, titled The Bible
in Masonry. The internal source notes identify the printed page, Masonic heading,
and Bible citation supporting every answer. Obvious citation misprints in the
PDF were corrected without expanding beyond the source relationships.


USE
---

Keep all five files in the same folder. Open index.html in a browser to run the
test locally, or upload the folder to the website.
